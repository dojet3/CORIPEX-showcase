## Engineering journey

1. **Foundation:** modular application, asynchronous persistence, migrations, transaction boundaries.
2. **Trust:** private workspaces, PostgreSQL row-level security, protected identity/session boundaries and reliable auditing.
3. **Source intelligence:** secure intake, parsing and normalization, document versions and provenance.
4. **Research:** lexical/vector retrieval, current-Workspace source-backed answers and bounded follow-up context.
5. **Product and release:** integrated user journeys, cloud/operations acceptance and mandatory research quality evaluation — **still in progress**.

The original roadmap intentionally anticipated architectural extensibility, but a design commitment alone does not constitute implementation. The [capabilities and evidence record](capabilities-and-evidence.md) describes the narrower accepted feature boundaries.
