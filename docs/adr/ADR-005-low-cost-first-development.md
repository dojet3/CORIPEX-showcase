# ADR-005 — Low Cost First Development

## Status

Accepted

## Context

CORIPEX is a learning-first and portfolio-focused project.

Early development should avoid paid infrastructure and unnecessary API costs.

## Decision

Sprint 001 will use local tools, Docker Compose, PostgreSQL, Qdrant, and open-source development utilities.

Paid APIs, paid cloud hosting, and managed databases are postponed.

## Consequences

This keeps early development cost close to zero.

Some production features will be delayed until the project has enough value to justify them.
