# ADR-004 — React TypeScript Vite Frontend

## Status

Accepted

## Context

CORIPEX needs a frontend that is common, modern, and easy to explain in interviews.

The frontend should remain simple during Sprint 001.

## Decision

CORIPEX will use React, TypeScript, and Vite for the frontend.

React will provide the UI layer, TypeScript will improve code safety, and Vite will provide fast local development.

## Consequences

This stack is widely used and suitable for portfolio value.

The frontend should avoid unnecessary complexity in early sprints.
